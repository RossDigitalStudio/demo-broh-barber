# Demo Broh Barber

Landing page conceptual para Broh Barber, desarrollada por Ross Digital Studio.

## Objetivo
Mostrar cómo podría verse una web moderna y mobile-first para centralizar:
- servicios
- equipo
- trabajos
- horarios
- ubicación
- agenda
- WhatsApp

## Stack
HTML + CSS + JavaScript puro.

## Notas
- La demo usa imágenes de stock de Unsplash de forma temporal.
- Los enlaces de agenda, WhatsApp e Instagram apuntan a los accesos públicos visibles en el perfil.
- La web incluye `noindex,nofollow` porque es una propuesta no oficial.
- Lista para publicar en GitHub Pages, Vercel o Netlify.
